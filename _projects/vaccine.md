In this project, I designed and implemented a vaccination appointment scheduler that connects a Java command-line application to a cloud-hosted relational database on Microsoft Azure. The work included designing the database schema using an entity–relationship diagram, creating SQL tables, and implementing queries and procedures to manage patient records, appointment scheduling, and vaccine inventory. The system allows patients to securely log in, view availability, and schedule appointments while caregivers manage time slots and stock levels. By simulating supply constraints and enforcing consistency through the database layer, the application ensures accurate tracking of appointments and vaccine availability in a multi-user environment.


**Skills & Tools**: Relational Database Design · SQL · Java · Microsoft Azure · ER Diagrams · Transaction Management · Secure Authentication · Backend Systems

**Impact**: Demonstrates the ability to design and implement a reliable, database-backed scheduling system that integrates backend logic, cloud infrastructure, and user-facing functionality for real-world resource management.
